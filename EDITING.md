# How to edit the site (no HTML, ever)

The rule: **you edit the `.qmd` files; the site rebuilds itself from them.** Everything inside `_site/` is generated output — never edit it, and don't worry about breaking it, because the next rebuild overwrites it completely from your `.qmd` sources.

## The two-step workflow

1. **Edit the text.** Open the `.qmd` file for the page you want to change (the map below tells you which one) in any plain-text editor — VS Code, TextEdit in plain-text mode, even Cursor. It reads like a normal document: headings start with `##`, links look like `[text](page.qmd)`, and everything else is just prose. Change the words, save the file.
2. **Rebuild.** Either double-click `render.command` in this folder (if Quarto is installed on your Mac — one-time install from quarto.org), or just tell Claude "rebuild the site." Every HTML page regenerates from your edited sources. Refresh your browser to see it.

That's it. One file changed, whole site updated — navigation, styling, and all the other pages stay consistent automatically.

## Which file controls which page

| You want to change… | Edit this file |
|---|---|
| Landing page | `index.qmd` |
| A day's module notes | `modules/01-foundations.qmd` … `modules/06-ai-knowledge-market.qmd` |
| Module overview page | `modules/index.qmd` |
| A lab | `labs/day1.qmd` … `labs/day5.qmd` (overview: `labs/index.qmd`) |
| Setup instructions | `setup.qmd` (general) · `setup-wrds.qmd` (WRDS/Day 4) |
| Syllabus | `syllabus.qmd` |
| Tools guide / prompt gallery / verification card / resources / about | `tools.qmd` · `prompts.qmd` · `verification.qmd` · `resources.qmd` · `about.qmd` |
| Navbar links, site title, footer text | `_quarto.yml` (one file controls the chrome on every page) |
| Colors, fonts, buttons | `styles/custom.scss` |
| The masthead bar text | `styles/som-masthead.html` |

**Special case — skill pages.** The 41 pages under `skills/` are generated from your Barrios_Skills collection by a script. Don't edit them directly (a re-sync overwrites them); edit the source skill in `~/Documents/Barrios_Skills/skills/` and re-run the sync (or ask Claude).

**Figures and slides** are also generated: figures from `.tex` files in the course folder, slide PDFs from `slides.tex`. Ask Claude to change those — the text pages are the ones meant for your own hands.

## Things that live in ONE place on purpose

- Site title, navbar, footer → `_quarto.yml`
- All colors and fonts → `styles/custom.scss`
- Skill catalog + license block → regenerated by `scripts/sync_skills.py`

If you find yourself wanting the *same sentence* on several pages (a disclaimer, a date, a deadline), tell Claude — Quarto has a variables file (`_variables.yml`) for exactly that, and it's a five-minute setup once there's a real case for it.

## If something looks broken after an edit

Almost always one of two things: a link's parenthesis got deleted, or a `:::` block lost its closing `:::`. The rebuild will say which file and line. Undo your last change, or ask Claude to fix it — nothing is ever lost, because `_site/` regenerates fresh every time.
